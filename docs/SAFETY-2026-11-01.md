# SAFETY — 2026-11-01

Four release-safety gates, run before this repository is shared or published.
A gate that was not run is `not run`, never `pass`.

| Gate | Status | Note |
| --- | --- | --- |
| 1. Code safe | **pass** | No credential at rest; all secrets come from the environment. |
| 2. Artifacts safe | **action required** | `.scratch/` (114 files, 776 KB) carries local absolute paths and would ship. |
| 3. Git history clear | **pass, one accepted risk** | 135 commits, zero secret-shaped strings. Local usernames appear in `.scratch` evidence paths. |
| 4. Running instance safe | **pass, two caveats** | Loopback binds, env credentials, egress allowlist. No provider spend cap; `/healthz` unauthenticated by design. |

## Gate 1 — code safe

```
$ git grep -I -n -E "(sk-[A-Za-z0-9]{20,}|syt_[A-Za-z0-9_-]{20,}|ghp_[A-Za-z0-9]{20,}|AKIA[0-9A-Z]{16}|-----BEGIN [A-Z ]*PRIVATE KEY-----)" -- .
(no output)
```

Every credential is environment-supplied, never at rest in the tree:

```
BUILD_SIGNING_PRIVATE_PEM   EVENT_SIGNING_PRIVATE_KEY_PEM   SECRET_MASTER_KEY
BUILD_SIGNING_PUBLIC_PEM    EVENT_SIGNING_PUBLIC_KEY_PEM    CAPABILITY_SIGNING_KEY
EVIDENCE_SEALING_KEY        DATABASE_URL                     EVENT_ANCHOR_WITNESS_TOKEN
```

The process starts with none of them set and emits a sentence, not a traceback:

```
Warning: CAPABILITY_SIGNING_KEY unset: using ephemeral capability signing key (not durable across restarts)
Warning: EVENT_SIGNING_*_PEM unset: using ephemeral Ed25519 event signing key (not durable across restarts)
Warning: EVIDENCE_SEALING_KEY unset: using an ephemeral key; sealed evidence cannot be decrypted after restart
```

**Caveat:** the fallback is an *ephemeral* key — correct for a demo, never for a
deployment. A production start must fail closed rather than silently mint a key
that dies with the process. Tracked as ticket 04, item 3.

## Gate 2 — artifacts safe

```
files: 322      bytes: 3,387,494      files > 200 KB: 0
.scratch: 114 files, 775,594 bytes
```

Weight is fine. Content is not: `.scratch/` holds session evidence containing
local absolute paths, e.g.

```
Error [ERR_MODULE_NOT_FOUND]: Cannot find module 'C:\Users\<user>\projects\ai-security-layer\src\anchors.ts'
```

That is a Windows username and directory layout — not a secret, but it is
personal-environment data and it should not be in a published tree.

**Action:** exclude `.scratch/` from any published or handed-off artifact, and
build that artifact with a script that refuses on token-shaped strings and on
`C:\Users\`. There is no such script yet (there is `scripts/` for setup only).

## Gate 3 — git history clear

```
commits: 135
secret-shaped strings across all history: 0
files ever added matching (.env|.pem|.key|.p12): none
```

No credential was ever committed. The only personal data in history is the
`C:\Users\<user>` path inside `.scratch/` evidence files. Accepted explicitly
below rather than rewritten, because a history rewrite costs more than it buys
for a username that is already public in this file.

**Decision (accepted risk):** `.scratch/` paths stay in history. If the repo is
published, `.scratch/` is removed from the *tree* and its presence in past
commits is stated here. If that becomes unacceptable, publish a squashed `v1`
instead — decided before the first push, not after.

## Gate 4 — running instance safe

```
src/rest-api.ts:256:      this.server?.listen(0, '127.0.0.1', resolve);
src/egress-proxy.ts:107:  this.server?.listen(0, '127.0.0.1', resolve);
wildcard binds: none
```

- **Own credentials:** every secret is an env var; `.env` is gitignored.
- **Surface closed:** both servers bind loopback only; TLS is the deployment's
  job (`DEPLOYMENT.md`); `/healthz` is the single unauthenticated route and is
  tested to carry no secret material.
- **Egress:** deny-by-default network gateway plus a proxy with DNS pinning and
  private-range blocking; H7 content-level DLP on bodies.
- **No execution from untrusted input:** tools receive an `ExecutionContext`
  with no issuance handle (invariant 4), and H5 refuses authority keys in params.
- **Auditable:** hash-chained, signed, anchored event log; `npm run adversarial`.
- **One-command stop:** `node src/cli.ts incident freeze` / `revoke-all`.

**Caveats:**
1. **No spend cap.** The model adapter has timeouts and bounded retries, but no
   per-day call or token ceiling. A stranger running this against a paid provider
   can generate a bill. Ticket 04, item 2.
2. **`/healthz` is unauthenticated.** Intentional (H15: liveness must be
   observable without credentials). It exposes dependency *status*, not content.

---

## Verdict

Safe to share as a **source archive after excluding `.scratch/`**. Safe to run
locally as-is. **Not** safe to expose on a public interface without TLS, a
provider spend cap, and the ephemeral-key fallback replaced with a fail-closed
check.
